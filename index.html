5. Lab procedure

AIM

To simulate CPU scheduling algorithms and calculate completion time, turnaround time, waiting time and average performance measures.

Procedure

  1. Enter each process ID, arrival time, burst time and priority.
  2. Select a scheduling algorithm and enter its time quantum if required.
  3. Click Run simulation to generate the schedule and Gantt chart.
  4. Observe the execution order and operation log.
  5. Read CT, TAT and WT from the result table and compare the averages.

How to extract values from a problem

  • AT: time at which a process enters the ready queue.
  • BT: CPU time required by the process.
  • Priority: use only if the question specifies a priority-based rule; here it is used to order MLFQ arrivals only as a tie-breaker.
  • Time quantum: maximum time slice for RR. For MLFQ, level 1 uses this value and level 2 uses its separate quantum.

6. Algorithm reference

Pseudocode — FCFS
Sort processes by arrival time (stable order).
time = 0
For each process:
    If time < arrival: time = arrival
    start = time
    time = time + burst
    completion = time
    TAT = completion - arrival
    WT = TAT - burst

FCFS is simple and non-preemptive. A process that arrives first gets the CPU first.

Pseudocode — non-preemptive SJF
time = 0; completed = 0
While completed < number of processes:
    Find arrived, unfinished process with smallest burst
    If none: advance time to next arrival
    Else: run it until completion
          calculate CT, TAT and WT

SJF chooses the shortest burst among processes that have already arrived. It does not interrupt the running process.

Pseudocode — Round Robin
Put arrived processes in ready queue
While unfinished processes remain:
    If queue empty: jump to next arrival
    Else:
        remove front process
        run for min(quantum, remaining burst)
        add newly arrived processes to queue
        If process remains: add it to queue tail
        Else: record completion time

RR gives each ready process a fair CPU time slice. A smaller quantum improves responsiveness but increases context-switch overhead in real systems.

Pseudocode — simplified 3-level MLFQ
New processes enter Queue 1 (highest priority)
Queue 1: Round Robin using quantum Q
Queue 2: Round Robin using quantum 2Q
Queue 3: FCFS (runs until completion)
If a process uses its full quantum and is unfinished:
    demote it to the next lower queue
Always choose the highest non-empty queue

This teaching version uses three queues, demotes CPU-bound jobs after their full time slice, and does not implement priority boosts or I/O blocking.

C reference code — FCFS

This is a compact lab reference for FCFS. The browser simulator itself is implemented in JavaScript.

#include <stdio.h>
int main(void) {
    int n, i, p[50], at[50], bt[50], ct[50], tat[50], wt[50];
    int time = 0, temp;
    printf("Enter number of processes: ");
    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        printf("Enter PID, arrival time, burst time: ");
        scanf("%d%d%d", &p[i], &at[i], &bt[i]);
    }
    /* Sort by arrival time; ties retain input order. */
    for (i = 0; i < n - 1; i++) {
        for (int j = i + 1; j < n; j++) {
            if (at[i] > at[j]) {
                temp=at[i]; at[i]=at[j]; at[j]=temp;
                temp=bt[i]; bt[i]=bt[j]; bt[j]=temp;
                temp=p[i]; p[i]=p[j]; p[j]=temp;
            }
        }
    }
    for (i = 0; i < n; i++) {
        if (time < at[i]) time = at[i];
        time += bt[i]; ct[i] = time;
        tat[i] = ct[i] - at[i];
        wt[i] = tat[i] - bt[i];
        printf("P%d CT=%d TAT=%d WT=%d\\n",
               p[i], ct[i], tat[i], wt[i]);
    }
    return 0;
}

FAQ

How do I calculate turnaround time?

TAT = Completion Time − Arrival Time.

How do I calculate waiting time?

WT = Turnaround Time − Burst Time.

Why is there an IDLE block?

The CPU is idle when no process has arrived and no process is ready to execute.

Which algorithm is preemptive?

SRTF and RR are preemptive. This simulator's FCFS and SJF are non-preemptive. MLFQ can switch between queues at time-slice boundaries.

Does SJF mean the shortest process overall?

No. Non-preemptive SJF chooses the shortest burst only from processes that have arrived and are ready at the decision time.
